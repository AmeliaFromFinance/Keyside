# Editor tips

## Find a key

Press Ctrl+K (⌘K on a Mac) or the search button in the top bar. Type part of a label, the second line, an action name ("switch scene") or a plugin name ("OBS"). Results come from every layout and page. Use the arrow keys and Enter, or click a result, to open that page with the key selected.

## Copy and paste between layouts

Ctrl+C, Ctrl+X and Ctrl+V (or right-click a key) copy, cut and paste keys with all their actions. The copied keys stay available when you switch layouts or pages, after a reload and in other editor tabs of the same browser. Pasting at a cell keeps the arrangement of several keys when they fit there.

Folder keys only paste into the layout they belong to, since the folder page lives there.

## Templates

Right-click a key, or a selection of keys, and choose **Save as template**. Templates are stored on the PC that runs Keyside, so every editor sees them in the **Templates** group at the top of the button palette. Place one like any action: click it and then a cell, or drag it onto a cell. Templates with several keys keep their arrangement. Hover a template to rename or delete it.

Templates saved from a phone or tablet follow the same rules as layout changes from there: steps that start programs can't be added, and new keyboard steps wait for approval on the PC.

## Review before pushing

**Push to phones** first lists what changed since the last push, per layout and page: keys added, removed, moved or changed, and pages or layouts added or removed. Press **Push to phones** there to send it. Ctrl+S still sends right away, without the review.

## Key images

Drag an image file (PNG, JPEG, WebP, GIF or SVG) from your desktop onto a key to use it as the picture of that key, or onto an empty cell to make a new key with it. A crop step shows first: drag to move the image, zoom with the slider or the mouse wheel. The square is what the key shows. **Upload image** in the icon picker uses the same step.

## Icon packs

In the icon picker, **Import icon pack** takes an Elgato Stream Deck icon pack (`.streamDeckIconPack`) or a plain zip of PNG, JPEG, WebP, GIF or SVG files. Each pack gets its own tab with a search over icon names and tags (for plain zips, folder names count as tags). Import a pack again to update it.

Only image files are taken from a pack, up to 1500 icons of at most 512 KB each and 50 MB per pack. Packs are imported in the editor on the PC. Deleting a pack removes its icons, except those a key or template still uses.
